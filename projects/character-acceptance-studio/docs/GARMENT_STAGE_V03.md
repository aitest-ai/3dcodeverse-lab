# 0.3.0：服裝局部修版與跑步姿態

基準為 Draft PR145 commit `30d0165b7d387442befc02aca5b4207e305bf69d` 的兩份0.2.0母檔；本階段使用獨立分支 `feat/character-studio-v03-garment-posture-20261104`。上游原檔、所有舊候選與交付包保留，不合併 main、不更新其他地圖網站。

## 本輪修改

Harbor 原領片只有8個頂點、領巾只有5個頂點，整片跟頸骨走，跑步時離開胸口。新版本以實際外套表面與同一角色的 barycentric 權重建立窄領片、領巾、連續胸前內衣片，移除過大的僵硬領圈，重配口袋及前背帶。外套胸部與腰部有局部布料鬆量／平滑，不縮放人物；胸前材質粗分界由連續衣片取代。背帶及衣片採分層厚度與間距，尚非布料模擬。

袖口原管徑與手腕不合、後置 Solidify 的邊緣在動作中出現細尖。新袖口依原手腕截面做橢圓漸縮、內外表面與兩端閉合，再配置前臂／手掌過渡權重；每個袖口560頂點，冷讀檢查每條邊恰好連兩面。原始0.2.0拓樸仍可查，新拓樸、UV及完整 before／after 記錄在 `garment-change-log.json`。閉合只證明結構，不代表每一格與皮膚都無交叉。

阿伯沿用原 MRT T-shirt 的1391頂點、1350面及UV，不重做或等比例放大。衣襬延長最多18mm，依實際身體／褲面從軀幹內往外取徑配鬆量，限制局部位移並平滑。腰腹另外從**同一人物**的身體取權重場，平滑轉移並保持標準骨名與正規化權重，消除測試跑步姿勢中衣服與腹部變形不同造成的小穿點。完整身體與褲子均保留，沒有刪除或遮罩皮膚來掩蓋問題。

0.2.0 的 spine 局部修正不足以限制實際身體軸。本版對 spine01 子樹迭代量測 pelvis→neck 的前傾，Run 由 Harbor17.62–20.76°／阿伯20.16–22.98°降至約12.00°；其餘動作也依實際軸限制，保留根與腿的原動作。Head forward 軸另限制俯仰，**不是眼球視線追蹤**；阿伯瞳孔偏上仍是已知問題。角度通過不等於重量感、肩肘及全身自然度通過。

## 失敗與剩餘缺陷

失敗的閉合大袖口、只拉長／改pelvis權重的阿伯衣襬，以及帶有錯誤最近表面法線投影的裂片版本，保留在 `evidence-v03/history/`。它們可通過根／腿數值檢查，卻在實際畫面失敗，已被退回，**不在最後registry中**。原始拓樸在0.2母檔，最終修改有完整可重建程式及前後資料。

- Harbor 胸側仍偏貼身，領片／領巾與內衣片的摺痕、腋肩過渡、背帶與包的縫接／碰撞需要繼續修版。不能把局部外翻改善說成完整外套已通過。
- 阿伯眼球視線偏上、手機握持未適配；原褲子後膝／小腿可見細裂片或露膚。本輪保留褲子與臉的原始幾何，沒有把這些問題算成已修好。
- 腰口前後取樣改善，仍需逐格確認所有扭轉、起停與轉身的布身／皮膚／褲面關係；沒有完整連續碰撞認證或物理布料模擬。
- 約12°跑步前傾是本輪慢跑候選設定；胸頸軸較直，不代表骨盆、頭部、肩肘、膝屈與速度／加速度的整體表演自然。Run起停／Walk↔Run未測。
- Harbor 上游完整未遮蔽的衣下身體仍缺；V110只有索引，V111／彩虹橋精確母檔仍缺。不回退V103，也不引用失敗V30／V31毛巾候選。

## 第二種身形與下一階段

共用的是前後比較、骨架語意／版本鎖、表面取樣與權重轉移工具、實際胸頸軸量測。不能共用同一個衣片版型、手腕尺寸、骨長或原始動畫陣列。阿伯使用自己的身體與褲面重新配版，沒有套用Harbor的尺寸或領片。

下一階段先對剩餘肩腋／胸側、背帶／包與阿伯褲膝、眼球視線／手機握持逐項修正，補充動態碰撞檢查與更密的局部畫面；由使用者／美術判斷自然度，再進目標引擎與手機真機驗收。另建立新版本，不覆寫0.3，也不直接發佈正式地圖模板。
