## 修正與來源邊界

- 手指彎曲在原生掌面與各指骨方向計算，不貼另一骨架的局部旋轉。最初過度握拳的實驗產生自交，已淘汰，未列入成品。
- 原 Run 前裙片與腿部有最多 32 對三角面交叉；前裙骨依原生大腿抬升提供鬆量，沒有等比例擴衣或改原拓樸。此法仍是骨骼修正，不是布料模擬。
- 原轉身上臂／大腿／小腿以世界方向求最小旋轉，缺少朝向造成軸向扭轉。新增朝向校正，保留骨頭位置，再於最後 15% 收回轉後的 Idle 姿態。轉身部分腿部動畫有變，需按新版證據判讀鞋底，不能引用前版接地數值當本版結果。
- 網頁根位移累積放在獨立 `motionOffset` 父節點。不能每幀直接改 AnimationMixer 擁有的動畫 root：常數通道可能跳過寫回，會累積旋轉，導致同一時間重複評估仍改變姿勢。
- 連續流程依固定相位和 SE(2) 世界位移銜接；不代表任意時刻混合控制器已完成。全網格位置接縫、重複求值與循環累積均有實測。
- 原 VRM SpringBone 停用時，原生骨頭 `matrixAutoUpdate=true` 仍必須保留；inverseBindMatrices 才是 skin rest，前階段修正不可退回。
