# 0.2.0：支撐腳、根位移與起停轉身

本階段建立於 Draft PR #142／commit `9c769f52b9d042327b92fc1ba7b64c6e476c07d6`，獨立分支 `feat/character-studio-v02-planted-locomotion-20261104`。不合併上游分支、不更換其他專案人物、不修改 main 或 v0.1 成果。

## 修改與範圍

v0.1 的循環接點與腳滑、以走路旋轉代替轉身、起停姿態混合，不能作正式遊戲模板。本次從**各角色自己的** v0.1 動作／rest pose 讀取局部 channels，不直接複製不相容骨架的 quaternion 陣列；保留 Harbor 65 骨、阿伯 53 骨及各自骨長、單位、前向軸與參考姿勢。

共用 Planner 提供腳印、支撐時間、步幅／配速及 root 軌跡，各角色依腿長、鞋底與站距重建：Walk 步週期 1.3333 秒、Run 0.9333 秒；走路約 0.723／0.634 m/s、跑步約 2.252／1.977 m/s（Harbor／阿伯）。這是本輪選定的慢走／慢跑候選，不是 v0.1 少量接地取樣推算的過快配速。

以可重現的 heel／flat／toe 支撐規劃、朝前膝 pole 的解析式 IK、實際變形鞋底高度、平滑腿長可達包絡及骨盆側向轉移烘焙 60fps。Start／Stop 1.7333 秒有三次腳位安排，兩步轉身 1.6 秒依序踏步到左右 90°，支撐腳世界朝向保持，與 Idle／Walk 接點對齊。GLB rig object 實際包含平移／yaw。重心轉移是動畫設計，未驗證物理 COM 或地面反作用力。

阿伯原鞋底隨 calf 彎曲，即使選定支撐點數值合格，瀏覽器實際鞋參考群仍漂移約 2.94mm。新版本只修 `TrueMPFBBody_oldman.shoes03` 的底部權重：沿鞋長 32 分段，底部 12mm 固定對應 foot，12–24mm 羽化回原權重；644 個頂點有完整 before／after。上部保留原 top-4 骨權重，原位置、拓樸、UV、表情、rest bones、貼圖 bytes／尺寸均不改。並未重建整雙鞋或整體縮放衣服。

動作是既有授權動畫加上本專案撰寫的接地／路徑修正，不是真人捕捉、Kimodo／NVIDIA 推論或自行訓練。沒有新增權重、憑證、付費或 GPU 假設。上游作者／授權與修改鏈見 `THIRD_PARTY_NOTICES.md`、v0.1 provenance lock、新 registry 與每角色 report。

| AI 畫面檢視 | 已查看代表性前側後、腳底、上身；保留胸口／衣襬／前傾等疑慮 | 使用者／人體動畫師／服裝美術的核准 |

錄影按鈕實際計時 6 秒，本環境 MediaRecorder 檔案長度約 5.253 秒；軟體繪圖會掉格，記錄見 recording-qa.json，不宣稱真機效能。

完整逐段數字在 `evidence-v02/numerical-qa.json` 與 `*-browser-mesh.json`，不能只看 PASS 標籤。烘焙循環及指定起停接點誤差在微米等級；瀏覽器另檢查真正接續播放時的關節位移，沒有用 crossfade 掩蓋接點。這是位置連續性與可操作性檢查，尚未證明速度／加速度每個接點都自然。

120Hz 的全鞋最低點為 Harbor 約 **1.45mm**、阿伯約 **2.26mm**，本輪所測平面／片段未觀察到鞋子穿過 y=0。支撐群在相同腳印及相同 pivot 區間允許最大累積漂移 2mm，實測最大值 Harbor 0.475mm、阿伯 0.256mm，另見 browser-metrics-summary.json。極短中間格仍有非零局部速度峰值（最高約 0.057 m/s），位置變化小於毫米；記錄保留，不宣稱零腳滑。測試門檻與人工自然度分開，若美術覺得滾腳或停步不自然仍應退回修正。

## 已知缺陷、失敗與未測

- **外觀未通過**：Harbor 胸前／領口版型呈突起、開襟與下襬輪廓生硬；實際 Run@0.2333s 近景另見領口片狀外翻及袖口細尖輪廓，列為失敗。腋下、跨肩帶與包仍需全動作逐格檢查。阿伯襯衫胸腹、下襬、褲襠／膝與手機的變形／碰撞也未核准。阿伯同時刻腰口可見鋸齒狀淺色邊緣，列為失敗；頭部／視線偏上也待修。精確觀察見 evidence-v02/visual-review.json。本輪沒有進行整件服裝碰撞解算。
- **動作自然度待修**：步幅／支撐穩定不代表重量感充分；慢走可能仍有膝屈與重心起伏。實際 pelvis→neck 軸在 Run 約 Harbor 17.6–20.8°、阿伯 20.2–23.0°前傾，不能把 spine 局部旋轉限制稱為已經完全挺直。跑步前傾與肩肘擺動仍需人體動畫師判斷。
- **失敗候選**：`evidence-v02/history/` 的初版蹲低、鞋底漂移及中途 QA 只供修正追蹤，沒有進 registry，也不是正式成果。v0.1 檔案仍保留供比較。
- **來源缺口**：Harbor 上游已刪除衣下部分身體，完整未遮蔽基底仍未取得；不能假稱所有身體拓樸完整。V110 只有交接索引，V111／彩虹橋精確修正母檔與動畫仍缺。V30／V31 毛巾沿用盤點結果，不把失敗包覆候選混入本版。
- **未測**：真機手機、Safari／Firefox、Godot／Unity、實際遊戲控制器 root extraction、斜坡與地形接地、Run 起停／Walk↔Run、自動服裝換裝與人體美術。禁止自動推到其他地圖。

## 第二種身形可共用與需手修

可共用的是語意設定、接地規劃、編輯／驗證工具、版本鎖與觀察格式；不能共用同一骨長、鞋底索引、站距或原始 local channels。阿伯成功重建相同七種動作，但需要個別 rest／腿長／鞋基準，且本輪已實際手訂鞋底權重規則。肩胸腰臀、衣服鬆量、領口／下襬、手機與手掌碰撞仍需角色個別修版，不可把 Harbor 衣服等比例放到阿伯身上。

## 下一個明確階段

先對 Harbor 胸口／領口／腋下／下襬做局部可編輯版型與權重修正，在本版七段及近景重新驗收；再將規則適配阿伯襯衫與褲襠，另建版本而非覆寫 0.2.0。跑步前傾／肩肘與重心自然度同步列入退件項目。取得人工美術確認及目標地圖的 root motion 實測前，不建立正式遊戲模板。
