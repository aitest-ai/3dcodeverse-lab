## 本輪選擇與成果

直接取用 Vivi 0.3、Vita 0.2 及各自的 Blender 母檔，建立 Vivi 0.4、Vita 0.3。兩人的原生身形、衣鞋、骨數及比例保留。Run 增加 MCP 指根彎曲，PIP 彎曲保持在經測試的較小範圍；較深握拳試作已拒收。新增手掌對裙片的檢查，找出前版後擺穿裙問題，使用各角色獨立的平滑上臂外展曲線避讓：Vivi 額外 2–20°，Vita 2–16°。手臂長度、前臂局部旋轉及手肘彎曲角度保留。

共享的是語意、掌面／指骨方向求法、檢查與匯出程式。每人使用自己的 rest frame、掌寬、母檔、來源雜湊及服裝避讓曲線。沒有把另一位人物的局部旋轉直接搬過來。此輪沒有重新擬合肩胸腰臀版型；衣袖、全身衣物碰撞及自然度仍需人工檢查。

GLB 只附加 30 根手指與 2 根上臂的 Run rotation 輸出。保留全部原 BIN、幾何、UV、權重、材質、原貼圖與 VRM metadata，其餘六段 JSON 完全相同。Blender 保留全部非目標原生動畫曲線並逐項核對。新版母檔可冷開、重新匯出；兩包從乾淨目錄可逐檔驗證、重建 byte-exact GLB 並在 Chromium 載入，實測結果以同包 `delivery-smoke.json` 為準。

## 驗收分類

- 程式／來源：GLB 結構、32 個允許變動的通道、原生非目標曲線、版本與 SHA；細節在 `source-preservation.json`、`validation.json`。
- Blender：背景冷開、原生表面、動作與匯出；未做離線美術渲染。
- 瀏覽器：Chromium + SwiftShader 實際模型、120 Hz 取樣、七段動作、起停／轉身、同鏡位比較、逐格、速度、錯誤提示與 Run 循環接縫。指定手部自交叉及手部／裙片交叉分別統計；不代表全身碰撞通過。
- 影像：兩人各前／側／背面、左／右手 4 相位，共 40 張實際 canvas 畫面與 2 段 WebM。軟體錄影會掉格，實際長度在 `video-probes.json`。
- 手機真機、人工美術、Godot／地圖整合：未測。390px 是桌面瀏覽器視窗測試。
