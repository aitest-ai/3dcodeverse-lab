# Character Acceptance Studio

User-authorized isolated browser acceptance tool. Keep all original source assets immutable.
Use the locally available Blender in background mode and report its actual version. Blender 5.2.3 is required for the MPFB native sources; 4.3.2 can read Harbor sources. No GUI/GPU claim follows from these tools.
New exports are candidates, never art-approved by code. Pin asset ID + version + SHA-256. Never overwrite source models, merge another branch wholesale, merge PRs, deploy sites, or replace other maps' assets. Preserve licenses, original texture bytes and dimensions, per-character rest transforms and semantic profiles. Browser, offline, hardware and human approval are separate evidence categories.
