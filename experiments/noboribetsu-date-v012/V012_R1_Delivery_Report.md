# 登別伊達時代村 V012 R1｜路面—草地柔化交付報告

**日期**：2026-11-02（臺灣）。**定位**：V011 原有 231.57 公尺步行場景的局部美術候選版；非正式發布。

## 這輪真正改動

- 對應 V006 最後約 33.84 公尺道路。沿原凍結 V002 GSI 高程、V006 GLB 與 V011 路線製作 **656 頂點／972 三角面**的獨立土色—草色漸層路緣，設為 B 場景視覺用、透明且不參與碰撞。
- 從道路邊約 3.03 公尺延伸到中心線側向約 3.64 公尺，最大路面／地形高程差約 0.108 公尺；不是測繪道路寬，也不是排水溝。
- V011 的 **148 格／296 面**地形補洞不動；原始 B、A、各擴建 GLB、道路碰撞、路線、人物、貼圖與 V010 低幀率控制均不修改。

## 真 WebGL2 驗證

- Xvfb + Chromium + ANGLE SwiftShader 正式建立 WebGL2，完整載入原高品質場景及新增路緣；B 畫面實際繪出 **1,434,226 面（雙面渲染會將新增 972 面計為 1,944 draw triangles）**，96 geometries、47 textures。
- A 首次載入、切回 B，姿態零漂移；瀏覽器無頁面例外。
- 手機直式 Chromium 模擬雙指操作通過：位移 **0.792 公尺**、放手後 0 漂移。非 Android 真機。
- 同鏡位的 V011 舊圖與 V012 新圖可在自足 HTML 中拖動滑桿比較。效果特意克制，**不宣稱遠景山坡整體已改善或 FPS 獲得固定提升**。
- 受本機 top-level 導覽限制，隔離測試用 virtual subresources + Python 實際預驗 SHA 的**測試專用** digest adapter。正式 app.js 原生 WebCrypto digest 仍保留，adapter 不入 Runtime；因此這項測試**不等於私人網頁 HTTPS 驗收**。

## 封存與重建

- V011 原始 101 個檔案中 97 個 SHA 不變；4 個檔案因新增路緣資訊修改，另增加路緣 JSON、V012 本機啟動器、README、差異 QA，共 **105 個檔案**。
- 從凍結來源乾淨重建後 **105/105 個檔案逐位元一致**。兩份 ZIP 經完整 CRC 測試。
- `v012_road_grass_fade_editable.glb` 是獨立可匯入的新增幾何，**不是**已經製作好的 Blender 正式 `.blend` 母檔。
