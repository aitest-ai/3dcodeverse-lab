# V009 本機啟動

1. 解壓整份 ZIP（保留 `dist` 資料夾）。
2. 需電腦安裝 Python 3.10+，執行 `python start_v009_local.py`。
3. 開啟 `http://127.0.0.1:8769/`，先確認 B 場景、再切 A、返回 B；走到 V009 商家街並返回入口。
4. 若顯示沒有 WebGL2，請改開 `http://127.0.0.1:8769/review_v009.html` 看診斷比較；不能當作 3D 驗收。
5. Android 真機可在**安全的內網 HTTPS 部署**後測試；本版本尚未設定安全的手機預覽網址，請勿直接暴露本機伺服器到公網。

V009 為估計外觀候選，完整實景與 Blender-native 尚未通過。未修改 V008 正式／私人網站。
