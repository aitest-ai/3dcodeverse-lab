# 登別伊達時代村 V004 候選 R1｜商家街第一段

**狀態：新增道路、三棟建築外觀模型與第一人稱程式已完成；尚未通過 V004 真正瀏覽器畫面／Android／Blender 正式母檔驗收。**

## 內容與操作

沿用 V003 R3 完整 B 精修模型與首次按 A 才載入 A 的排程；道路擴建約 47.1376 公尺，整段約 130.0146 公尺。新增高等学問所、北京亭、七万石外觀。新增 3 份具體 GLB（道路、外觀、招牌）、衍生道路碰撞與新路線。

解壓 Runtime ZIP，使用 **Python 3.10+** 在此資料夾執行：

```bash
python start_server.py
```

然後使用支援 **WebGL 2** 的瀏覽器開啟 `http://127.0.0.1:8765/`。不可直接雙擊 `index.html`：正式檔案 SHA-256 檢驗需要 localhost 或 HTTPS 的安全環境。首次載入需完整 B 模型，請看畫面進度；左側虛擬搖桿移動、右側轉動視角，電腦可使用鍵盤及滑鼠。A 是地理骨架，B 是場景外觀；切換時位置不應改變。
