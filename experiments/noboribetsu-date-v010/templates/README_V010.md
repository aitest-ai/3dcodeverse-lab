# 登別伊達時代村 V010 R1｜執行包

這一版沿用 V009 的 231.5664 m、完整場景及全部 GLB，不覆寫任何既有版本；僅修復低幀率下的移動時間計算及按鍵/搖桿放手處理。

1. 安裝 Python 3（已安裝可略過）。
2. 在解壓的本資料夾執行 `python start_v010_local.py 8770`。
3. 在**同一台電腦**使用最新版 Chrome/Edge 開啟 `http://127.0.0.1:8770/`。
4. 等待完整 B 載入，點「開始步行」；用 W/A/S/D、觸控搖桿與視角拖曳測試。回入口／街尾返程、A/B 切換應保持位置及視角。
5. 若 WebGL2 失敗，可查看 `dist/review_v009.html`（舊版的靜態同鏡位圖）；不要視為真實遊玩已通過。

**安全來源警告**：如果手機透過區域網路 IP 存取電腦的純 HTTP 網站，WebCrypto 可能不可用，完整性驗證會正確拒絕進場。Android 真機需要 HTTPS 網址且仍待驗收。

**已知問題**：在 231.6m 尾段的真 WebGL 畫面能看到地形黑白鋸齒接縫，未修正。美術、Blender 原生母檔與私人站 CDN/登入仍未驗收。
