## 本輪完成

- 以 V012 231.5664 公尺高品質場景為基準，沿 V004（約 s=82.877–130.015 m）與 V005（約 s=130.015–197.724 m）道路補強外側土色—草色透明過渡。**沒有延長路線、修改模型或重做已修好的屋頂、建築與地形。**

- 新增 B-only **2,436 個幾何三角面（V004 840、V005 1,596）**、1,688 個頂點、4 色階 RGBA 漸層。地形採凍結 V002 高程；新路緣約延伸至道路中心線側向 3.82 公尺（從 3.39 公尺起），均為作者估計的視覺尺寸，**不是測量路寬、排水溝或新的地理資料**。
- V011 的 148 格／296 面地形補洞、V012 尾段 972 面路緣、原有 231.57 公尺路線、原始 B/A 高品質模型、碰撞及手機／鍵盤操控全部保留。原 V012 105 檔中 **101 檔完全不變、4 檔介面與程式設定更新**；另增 3 檔，共 108 檔。

## 真實驗證

- 以原版模型獨立 SHA-256 檢查後，在 Chromium + Xvfb + ANGLE SwiftShader **成功建立 WebGL2**，完整 B 場景載入，實際渲染結果約 **1,439,098 draw triangles、97 geometries、47 textures**（單次軟體繪圖診斷值，不可當作硬體 FPS）。
- V011 296 面地形補洞、V012 972 面路緣及 V013 2,436 面路緣，均由實際場景的載入診斷確認。
- 以測試專用的商家街鏡位設定，分別拍攝 V004 與 V005 路緣開／關的 WebGL2 截圖。V005 可辨識到克制的局部色彩差異；V004 在此鏡位差異極小，**不宣稱其美術品質已大幅提升**。
- 所有新模型三角面均有正面積，沒有三角面索引越界。V004／V005 原始路面、所有建築、V011 補洞、V012 路緣與碰撞的 SHA-256 保持一致。
- 自凍結 V012 Runtime ZIP 與 V002 Complete ZIP **重新建置 108/108 檔案逐位元相同**。兩份新的 ZIP 進行完整 CRC 驗證。

## 驗收界線

本機阻擋瀏覽器對 localhost／HTTPS 的頂層導覽，因此隔離 WebGL2 驗證使用虛擬子資源及**僅供測試**的雜湊回應器，模型的真實 SHA-256 已事先由 Python 核對；正式 Runtime 仍使用 `crypto.subtle.digest`，**沒有**內建測試替身。

本輪使用測試用鏡位放置觀察局部美術，**不代表角色實際走完 V004／V005 街段**。沒有重新執行 Android 實體手機、私人預覽網站 HTTPS/CDN/登入、Blender Native `.blend`／Cycles 或現地建築尺寸驗收。上一輪通過的手機模擬不代表這輪實體手機已通過。
