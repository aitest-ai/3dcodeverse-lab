# 臺北機甲 v6.0｜臺北 101 防衛戰

## 來源與依賴

此分支從 v5.9 三型敵機 Draft PR #58 延續，不合併 main、不更新公開遊戲站、不替換原本 v5.0 方形 15-bone GLB／Blender 可編輯母檔。本倉庫保存獨立可測的 **mech-mission-v60.js**、Node 22 測試和整合規格；完整 Windows Slop Taipei 疊加包另以 ZIP 獨立交付，**不是整份存放在此倉庫**。

共用核心版本的 Git blob SHA：`42b79732b28975bdcd5616772477d8d474cc41e1`（應與完整 ZIP 的 `mech-mission-v60.js` 完全一致）。

## 任務規格

- 從正式 `TELEPORT_LOCATIONS.taipei101` 傳送點進入，距離 240 公尺內，利用真實 `controllerManager.getGroundHeight`、OSM `ColliderGrid`、水域與車流篩選路面。找不到中繼站或任何一個敵機安全位置，則 **deployment_failed**，不能產生空波次勝利。
- 臨時「訊號中繼站」是新增加的遊戲虛構模型，不是假冒 101 大樓原有設施；不修改臺北 101 真實建築。玩家或中繼站歸零、超時或離開防線即失敗。
- 三波：突擊×2；突擊×2＋遠距×1；突擊×2＋遠距×1＋重裝×1。每波實際敵方 HP 歸零、傳入獨立敵機 ID 才可前進，不可手動改計數偽造清除。
- 遊戲內 300 秒倒數、波次間 4 秒整備、玩家切換非機甲模式時暫停模擬、渲染停滯更新最多 0.05 秒。倒數是遊戲更新時間，不是牆上時間。
- 遠距、重裝及部分突擊型敵機優先攻擊中繼站，原本 v5.9 攻擊前預警、射線遮擋／真正缺口、真實 HP 邏輯不變。
- Windows 遊戲 HUD 新增關卡倒數、中繼站耐久、波次、剩餘敵機、勝敗與得分；M 開始／重試，R 還原自由戰鬥。原城市的 V 攝影機快捷鍵在機甲模式被關閉，以免與側閃衝突；其他模式保留原本功能。
