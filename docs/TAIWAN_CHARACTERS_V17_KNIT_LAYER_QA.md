# 臺灣人物 V17｜原生 CC0 毛衣與褲子前後遮蔽修復實測

日期：2026-10-31（臺灣時間）。**此版仍是美術驗證草稿，不得正式發行或合併 main。**

## 目的與根本原因

V16 原始 MPFB 4 人輸出成功，骨架 53、真正人體 13,380 頂點、10 個官方 Faceunits Morphs；保留了原始褲子的面，卻讓老闆娘胸腹部以下出現大片灰黑色穿模。因為針織毛衣的一部分實際上位於褲裝網格的後方，單純不刪面並不能得到正確的衣物層次。

V17 建立 `scripts/taiwan_characters/garment_layer_v17.py`：在同一條實際 Blender 相機方向射線上，比較毛衣與褲子的表面深度，只微幅向前修正**毛衣真正朝前、可見的表面頂點**。每個位移同步套用至該頂點原本所有 Shape Keys，保留原生 CC0 材質、UV、網格面、骨架權重。非正面、內層與大於 7 cm 的不合理偏移不得強拉出去。此修法不涉及塗黑或做假遮蔽片。

## 成功驗證的快速 GLB 比對

- 以 V16 實際輸出的 `boss_v16_ponytail01.glb` 為來源，Blender 5.2.3 真正匯入與渲染 V16 before，再套用 V17 幾何修正，同樣燈光／相機渲染 after，輸出 debug GLB 和結構報告。
- 快速版 GitHub Actions：[41138212851](https://github.com/aitest-ai/3dcodeverse-lab/actions/runs/41138212851)，成功；測試報告已有 ZIP artifact。
- 共調整 **207 個毛衣原始頂點**；最大外移 **9.65 mm**；原始毛衣及褲子網格頂點／面數均維持不變。
- 對毛衣與褲子都有命中的 530 條前視線，先前有 **59 條**由褲子出現在毛衣前方；修補後剩 **2 條**，錯層比例 11.132% → 0.377%。保留例外位置：左右 x 約 ±0.1533 m、z 約 0.9043 m。
- 視覺圖顯示腰部大片深色斑塊大幅改善，**但衣襬仍有小缺口與粗糙邊緣**；尚不符合正式遊戲美術品質。
- 嚴格限制：此快版是將 V16 GLB 重新匯入並再次匯出；重新匯入會為貼圖 UV/法線拆分頂點，不可拿來證明原始 MPFB 的 13,380 頂點約束。

3. 僅測試中性姿態，尚無走路、蹲下、手臂舉起時的動態穿模／表情穿模驗證。
4. 仍僅 4/8 位角色；不應發行正式八人角色 ZIP。
