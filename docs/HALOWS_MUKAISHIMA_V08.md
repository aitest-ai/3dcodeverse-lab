# Halows 向島店 V08｜近景精修與整合 Gate

## 目標
V08 從已通過 Blender 5.2.3 的 V07 另開，不覆寫 V07。只精修 Halows A棟與南側入口前場，不整合瀨戶內 Runtime，不更新網站。

## 真實資料
- Halows 官方向島店：尾道市向島町5533番地47；24小時營業。官方頁附外觀照與店區進出示意圖。
- 固定 OSM way 661155704：A棟 footprint／平面方向骨架。
- 尾道市 2017 大規模小売店舗資料：向島モール A棟為 Halows；歷史資料記載停車與駐輪設施、荷捌設施。只作配置方向與量級參考，不當 2026 測繪。
- 尾道市 Cycle Oasis 名單列出ハローズ向島店；這支持其作為騎行補給點，但不等於「渡船頭到店門」的每一段道路都已驗證為官方しまなみ主線。

## 路線 Gate
官方店頁的進出示意圖以國道317號側為主要顧客車流參考，但頁面本身提醒道路與周邊環境可能不是最新。V08 不會把汽車進出箭頭直接變成自行車導航。東西橋現況轉向、藍線／自行車路權、店前自行車通路與玻璃店門位置仍需另外確認。
