## 本輪改動
1. 整理塔樓招牌：移除 V10 不太像實景的三組紅柱標示與 24H 字樣；以兩組紅色竪板與綠色圓形、正面片假名、側面 HALOWS 文字重新建立有厚度的幾何。
2. 拱形入口：將顯得浮在空中的白色拱管縮細，增加淺色建築凹面；不推定店內深度。
3. 牆面：移除多層重複而過深的水平／垂直接縫，對粉色柱身補細淺的分格，改善近看規律裂紋感。
4. 玻璃入口：保留 V10 中空外殼，增加推拉門頂底軌、握把、反光金屬、雨棚底面，全部是外觀示意而非已確定的門機構。
5. 地面：以**可重現的原創程序生成** 2 張鋪面與柏油色彩貼圖，套用到停車場、入口鋪面及周邊可視道路。使用 UV 公尺尺度重複；原貼圖與已打包 GLB 都可取得，不使用付費資產。
6. 驗收：完整保留 V10 五張同鏡位 Blender 圖，新增 `tower_identity` 及 `apron_detail`，共七張。模型同時輸出可編輯 BLEND、GLB、貼圖、manifest、report 與原版 site_lock。

## 必須分開判斷的驗收
- Blender CI 的 PASS 只能確認實際模型產生、GLB 結構、圖像檔、貼圖封裝與雜湊；**不代表已達寫實**。
- 需要逐張看真實 Blender render，特別是招牌、拱形、門框與停車場微材質。不佳的部分要再修正，不能以新版本名稱取代美術審核。
- 需要另以 GLB 冷回讀檢查貼圖與法線；Blender 原生材質與 glTF runtime 可能不同。
- V06 完整騎行／渡船路線、Halows 店門與東西橋轉向、步行騎行碰撞、停車入口合法性、瀏覽器／Android 實玩，**全部沒有在這一輪通過驗證**。不得把車輛動線直接從官方汽車圖轉成自行車路線。
