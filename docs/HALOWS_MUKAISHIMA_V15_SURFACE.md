# V15 瀨戶內騎行世界：美術與渡船地理資料分層

## 與 V14 的實際分工
- 先維持真實 V14 Blender 幾何／來源，同一屋頂尺寸、道路 OSM way、GSI 地形及未驗證店門不改。
- V15 在 `scripts/blender5/halows_mukaishima_v15_surface.py` 以固定 V14 Git blob `7876eef919cdc0620daeb1e0478259ee06dde06b` 取回母檔來源幾何，獨立匯出 GLB／BLEND／七張可比較 Blender 渲染圖。
- 屋頂、主牆面、玻璃下緣、雨棚陰影及停車場原創低對比柏油貼圖都是候選美術修飾，**不是現場測量結果**。外牆增加細分構件後，仍必須比對官方照片、GLB 和近景，不能把平滑積木換成滿版規律線條就當寫實。
- 停車場路緣與行人／單車進場權限未查證，不新增入口、坡道、藍線或車道；V09 地理快照不改。
- 嚴格保留所有 V11–V14 舊版及原主網站；不合併 main、V06 Runtime／人物／單車／渡船不作替換。

## 兩條渡船線（資料證據，不是導航 3D 成果）
以尾道市官方網站 2025/07/01 更新的航路表為準：
1. **尾道駅前－向島富浜**（おのみち渡し船）。
2. **尾道土堂－向島兼吉**（おのみち渡し船）。
尾道市指出尾道大橋狹窄、車多，不宜騎車通行，建議自行車搭渡船。福本渡船已於 2025/03 停航，不列為可搭乘路線。

檔案 `docs/data/onomichi_mukaishima_ferry_v15.json` 刻意將港區坐標設為 null，尚未找到可靠、彼此一致的碼頭入口與現地自行車動線；兩條渡船只標示「航線存在」，不能立刻畫成尾道→Halows 的完整導航或遊戲線。無即時航班驗證，不推定當天開航或班次。

## 尚待真正驗收
- 從 V06 原始 Runtime 匯入已驗證渡船、碼頭、角色與單車；不使用 V05 或簡化盒子替代。
- 取得渡船向島端的實際車道出入、行人牽車區、東西橋與國道 317 交叉、Halows 自行車停放區、可安全通行的沿途道路證據。
- 與 V13 WGS84 平面鎖定比對的共同 **y 垂直基準**，目前未完成；不得加 2.70m 假裝接地。
- 模型道路及人物連續掃掠碰撞、店門通行、渡船上下船、Browser WebGL2 和 Android 需逐項驗收。
- 七張 Blender 圖、GLB 幾何與貼圖可以做美術 QA，不能作為 3D 遊玩通過證明。
