## 本輪真正完成的工作

V19 的修補只作用於已匯出的外送員 GLB。V20 在同一 Blender 程序中先執行固定 git blob 的原始 MPFB 四人建構，再對外送員的原生褲裝網格套用相同全腰覆蓋演算法，最後才匯出 GLB。沒有把現成 GLB 匯入後冒稱它是原始 MPFB 人體。V19 GLB 僅作固定 SHA256 的幾何與動作參照。

四位角色為 you（主角）、boss（老闆娘）、uncle（阿伯）、jie（外送員）。每個原始人體均為 13,380 真正人體頂點、53 根骨架、10 組人體表情。MakeHuman helper 已從來源網格移除；沒有用 MASK 隱藏。其他配件與服裝仍為獨立原生網格，不計入人體頂點數。

只有外送員的 `OpenSourceCloth_jie_cortu_cargo_pants` 在 V20 腰部回整步驟中允許改動。其他三人及外送員非目標網格的座標、面、UV、骨架權重和表情位置，均以本次原始建構前後的雜湊比對保持一致。貼圖另明確載入、縮至最大512像素、打包；因此沒有宣稱所有輸出檔與前版逐位元組相同。

## 腰部修補與動態結果

外送員原生褲裝為211頂點、196個面；腰口16點、T恤下襬36點。移動56個原生頂點，最大位移約38.728mm；不增刪面、UV或骨架權重。修後來源褲裝與固定V19參照幾何的雙向最大距離為 0.000000608981 m（約0.000609mm）。

採用原V19壓力片段：站立、抬手、彎腰、跨步及回復。來源骨架不是猜測Euler軸，而是將參照的全局關節變形轉回原生rest骨架。每一時間點檢查8方向×41×25＝8,200條射線，僅檢查 Z=0.94–1.13m 的腰部區域；1.5mm深度容許。排除手臂與手指的自然遮擋，不把領口露膚或紮衣的褲頭外層關係當成穿模。

來源模型修補前四個關鍵姿態的腰部露膚命中為134、136、173、135；修後49個時間點、401,800條射線均為0。把最後交付的動畫GLB重新匯入另一個乾淨Blender場景，再檢查同樣49個時間點與401,800條射線，露膚命中也為0。這是來源和交付品的重複驗證，不能說成98種不同動作，也不能保證任意連續時間、新動作、全身或其他三人都不穿模。

## 本輪修正的製作流程問題

- 原始貼圖採lazy-load，僅用 `has_data` 篩選會跳過尚未載入的圖，造成真正匯出的檔案超過6MB。現於來源匯出前真正載入像素、等比例縮小與打包。
- 重新開啟.blend後 `has_data` 也可暫時為false；回讀驗收現在先要求packed bytes存在，再解碼像素，不依賴runner的外部圖片路徑。
- 回讀檢查可獨立重跑，不必每次重新渲染四人。
