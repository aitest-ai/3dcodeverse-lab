開啟原版遊戲副本

請在新分頁的遊戲畫面右下角展開「V31 原版遊玩驗收記錄」。如面板未出現，應先查瀏覽器 Console，不要自行宣布通過。

② 實際應測的操作

  1. 先讓 3D 環境真的載入，檢查人物是否能走路、停下。
  2. 從步行切換騎車並退回步行，檢查人物有無漂浮。
  3. 左右轉彎、上坡，觀察車輪與車架是否合理。
  4. 切換第一／第三人稱，檢查鏡頭是否穿牆、撞到人物。
  5. 操作既有渡船功能，確認上下船與移動。
  6. 打開 V30 獨立工作臺，對同一原版模型測八個手腳接觸點。

③ 操作證據

原版遊戲副本的右下角有開始、停止、匯出 JSON 按鈕。只會記錄 WASD 等操控代碼、滑鼠／觸控種類、是否發生錯誤及人工確認項目；不蒐集鍵入文字、GPS 或滑鼠座標。

匯出的 JSON 要連同真實遊玩畫面（手、腳、自行車及鏡頭）一起檢查，才能判斷問題。

④ 保護原版

原本的 src/main.mjs、src/avatar.mjs、data/world.json 與原版 GLB 保持逐位元相同。新增功能只限獨立資料夾，網站不會自動部署，也沒有新可騎道路。
