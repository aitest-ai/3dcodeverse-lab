# Gemini — 3DCodeVerse Lab

Before interacting with any scene or 3D model, read `AGENTS.md` and `docs/SCENE_HUB.md`. The shared exchange tool is `scripts/scene_hub.py`, with scene catalogs under `scenes/catalog/`. Check licenses, checksum and quality status. Publish only when authorized on a feature branch followed by PR review. Never assume HY-World 2.0 inference is configured or that a procedural demonstration is a real reconstruction.
